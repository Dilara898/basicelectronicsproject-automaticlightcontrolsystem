# Project Title

## Automatic Light Control System Using LDR, Transistor, and Relay

---

# Project Description

This project is an automatic lighting control system that uses an LDR sensor, transistor, relay, and diode protection circuit. The system automatically turns the lamp ON during darkness and turns it OFF during daylight.

The main goal of this project is energy saving and automation. The project demonstrates practical applications of electronic switching, sensor systems, relay control, and transistor operation.

---

- To reduce unnecessary power consumption
- To understand transistor switching
- To learn relay interfacing

---

# Working Principle

When light falls on the LDR, its resistance decreases. This keeps the transistor OFF and the relay inactive, so the lamp remains OFF.

When the environment becomes dark, the LDR resistance increases. The transistor turns ON, activating the relay and turning the lamp ON automatically.

# Troubleshooting

| Problem | Cause | Solution |
|---|---|---|
| Lamp not turning ON | Incorrect transistor connection | Check transistor pins |
| Relay not activating | Low base voltage | Adjust potentiometer |
| LED not glowing | Wrong LED polarity | Reverse LED connection |
| Relay clicking continuously | High sensitivity | Readjust potentiometer |
| Circuit overheating | Short circuit | Check wiring |

# Conclusion

The Automatic Light Control System successfully controls a lamp according to surrounding light intensity using an LDR, transistor, relay, and protection diode. This project demonstrates automation, energy efficiency, and practical electronic system design.
